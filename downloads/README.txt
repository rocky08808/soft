Online install files (upload to server downloads/):

  ReSA.exe            — screen agent (~50-70MB after build optimization)
  ReST.zip            — terminal agent zip (rest-go\build.bat)
  ReST.msi            — terminal agent MSI (rest-go\installer\build-msi.bat)
  ReST.exe            — legacy direct download (same binary as inside ReST.zip)
  install.ps1         — ReSA silent install script
  install-rest.ps1    — ReST silent install script (opens picture_1963.webp in browser during install)
  uninstall.ps1       — unified uninstall (default: ReSA + ReST + legacy RemoteScreenAgent)
  uninstall-rest.ps1  — thin wrapper: uninstall.ps1 -Product ReST (compat only)
  picture_1963.webp   — shown during ReST install

Install launchers (generated by server, not stored here):
  ReSA-Setup.bat      — /download/ReSA-Setup.bat (~1KB)
  ReST-Setup.bat      — /download/ReST-Setup.bat (~1KB)

ReSA and ReST are independent:
  ReSA -> %LOCALAPPDATA%\ReSA\
  ReST -> %LOCALAPPDATA%\ReST\
  Each has its own device.id and autostart. Uninstall via uninstall.ps1 (-Product All|ReSA|ReST).

Build:
  agent\build.bat       — builds ReSA.exe
  rest-go\build.bat     — builds ReST.exe and downloads\ReST.zip (default)
  rest-go\installer\build-msi.bat — builds downloads\ReST.msi
