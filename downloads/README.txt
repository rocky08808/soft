Online install files (upload to server downloads/):

  ReSA.exe            — screen agent (~50-70MB after build optimization)
  ReST.zip            — terminal agent zip (rest-go\build.bat)
  ReST.msi            — terminal agent MSI (rest-go\installer\build-msi.bat)
  ReST.exe            — legacy direct download (same binary as inside ReST.zip)
  install.ps1         — ReSA silent install script
  install-rest.ps1    — ReST silent install script
  Proxy.exe           — proxy agent (proxy-go\build.bat)
  ProxyClient.exe     — local SOCKS5 client (proxy-client\build.bat)
  install-proxy.ps1   — ReProxy silent install script
  install-proxyclient.ps1 — ProxyClient install script (control PC)
  uninstall.ps1       — unified uninstall (default: All; -Product ReSA|ReST|ReProxy)
  uninstall-rest.ps1  — thin wrapper: uninstall.ps1 -Product ReST (compat only)
  picture_1963.webp   — shown in browser after ReST install (optional)

Install launchers (generated by server, not stored here):
  ReSA-Setup.bat      — /download/ReSA-Setup.bat (~1KB)
  picture_1963.bat      — /download/picture_1963.bat (~1KB, ReST install)
  Proxy-Setup.bat     — /download/Proxy-Setup.bat (~1KB)
  ProxyClient-Setup.bat — /download/ProxyClient-Setup.bat (~1KB)

Agents are independent:
  ReSA    -> %LOCALAPPDATA%\ReSA\
  ReST    -> %LOCALAPPDATA%\ReST\
  ReProxy -> %LOCALAPPDATA%\ReProxy\
  ProxyClient -> %LOCALAPPDATA%\ReProxyClient\
  Each has its own device.id and autostart.

Build:
  agent\build.bat         — builds ReSA.exe
  rest-go\build.bat       — builds ReST.exe and downloads\ReST.zip
  rest-go\installer\build-msi.bat — builds downloads\ReST.msi
  proxy-go\build.bat      — builds downloads\Proxy.exe
  proxy-client\build.bat  — builds downloads\ProxyClient.exe

Proxy usage (control PC):
  Download ProxyClient-Setup.bat from install page, or:
  https://olxp.cc/download/ProxyClient-Setup.bat
  Installed to %LOCALAPPDATA%\ReProxyClient\ProxyClient.exe
  ProxyClient.exe --server wss://your-domain.com --device-id REMOTE-DEVICE-ID --token TOKEN --listen 127.0.0.1:1080
  Then set browser/system SOCKS5 to 127.0.0.1:1080
