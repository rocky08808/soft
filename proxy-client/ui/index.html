启动后本机网络不受影响（默认不改动系统代理）。
1. 被控机 Proxy 显示在线后，流量才能走隧道
2. device.id 必须与被控机 ReProxy\device.id 一致
3. 点 「检测出口 IP」 验证 SOCKS 隧道（仅测 HTTP:80）
4. 勾选「系统代理」后 Chrome 走 127.0.0.1:8080 HTTP 代理（比 SOCKS 更可靠）
5. 仍不变请点 「用代理打开 ip.sb」，或 Firefox 手动 SOCKS5 127.0.0.1:1080

若网络异常：点 「恢复本机网络」 或 停止；不要用任务管理器强杀 ProxyClient。
也可运行 restore-network.ps1，或 ProxyClient.exe -restore-network
