不依赖 ReSA / ReST。安装后可在控制端浏览器设 SOCKS5，流量从被控机公网 IP 出去。

下一步：在「下载」文件夹双击 Proxy-Setup.bat（或 ReProxy安装.bat）。

1在被控机下载并运行 ReProxy 安装脚本
2查看 ReProxy 设备 ID（见下方「如何查看设备 ID」）
3在控制机下载并运行 ProxyClient-Setup.bat（见下方「控制端用法」）
4浏览器 SOCKS5 设为 127.0.0.1:1080，打开 ifconfig.me 验证 IP
如何查看 ReProxy 设备 ID

ProxyClient 的「设备 ID」填被控机 ReProxy 生成的 ID，与 ReSA / ReST 的 ID 不一定相同。安装并首次运行 Proxy.exe 后才会生成。

方法一：在被控机本地查看

文件路径（资源管理器地址栏粘贴）：

%USERPROFILE%\AppData\Local\ReProxy\device.id

ReST 终端：先确认 Shell 类型

终端 Shell 下拉框：PowerShell 用 $env:...；选 CMD 用 %USERPROFILE%。不要混用，否则报「语法不正确」或「找不到路径」。

检查是否已安装（PowerShell）：

dir "$env:USERPROFILE\AppData\Local\ReProxy"

检查是否已安装（CMD）：

dir "%USERPROFILE%\AppData\Local\ReProxy"

查设备 ID（CMD / Win+R，路径含空格务必加英文引号）：

type "%USERPROFILE%\AppData\Local\ReProxy\device.id"

若文件不存在，先启动代理（CMD）：

start "" "%USERPROFILE%\AppData\Local\ReProxy\Proxy.exe"

方法二：用 ReST 远程终端查看（无需到被控机跟前）

前提：被控机已装 ReST。在控制端连接后点「打开终端」。Shell 选 PowerShell 时：

Get-Content "$env:USERPROFILE\AppData\Local\ReProxy\device.id"

若文件不存在，先启动代理（PowerShell）：

Start-Process "$env:USERPROFILE\AppData\Local\ReProxy\Proxy.exe"

Shell 选 CMD 时，用上方「方法一」里带引号的 type "%USERPROFILE%\..." 与 start "" "%USERPROFILE%\..."。

方法三：看 ReProxy 日志

PowerShell：

Get-Content "$env:USERPROFILE\AppData\Local\ReProxy\proxy-agent.log" -Tail 20

CMD：

type "%USERPROFILE%\AppData\Local\ReProxy\proxy-agent.log"

找 Generated device ID: 或上线记录中的 ID。安装失败可查：%TEMP%\ReProxy-install.log

若文件夹不存在，说明 ReProxy 尚未成功安装，请重新运行上方「一键安装」命令。

Windows 安全中心误杀？

ReSA / ReST / ReProxy 均为未签名远程工具，Defender 可能提示「发现威胁」或拦截运行。安装脚本会自动尝试添加排除项；若仍被拦，请手动添加：

1打开 Windows 安全中心 → 病毒和威胁防护 → 保护历史记录
2找到 ReSA.exe / ReST.exe / Proxy.exe / ProxyClient.exe 相关项 → 操作 → 允许 / 在设备上允许
3排除项 → 文件夹 → ReSA %LOCALAPPDATA%\ReSA，ReST %LOCALAPPDATA%\ReST，ReProxy %LOCALAPPDATA%\ReProxy，ProxyClient %LOCALAPPDATA%\ReProxyClient
4再添加排除项 → 进程 → ReSA.exe / ReST.exe / Proxy.exe / ProxyClient.exe
5重新运行安装脚本，或重启 Agent 后再试

出现 Windows 安全提示？

未签名软件首次运行可能被拦截，属于正常现象。

1蓝窗 SmartScreen：点「更多信息」→「仍要运行」
2下载后无法运行：右键安装文件 → 属性 → 勾选「解除锁定」→ 确定后再双击
